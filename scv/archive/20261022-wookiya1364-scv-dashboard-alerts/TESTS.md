# Test Plan — SCV 칸 — 끝·오류·허락 기다림 알림과 휴대폰 알림

## Overview

다음을 검증한다.

- 2분 넘게 걸린 일이 끝났을 때만 알린다.
- 오류나 거절로 멈추면 바로 알리고 칸에 표시한다. 사용자가 멈춘 경우는 조용히 둔다.
- 하위 에이전트의 차례를 메인 차례로 착각하지 않는다.
- 허락 창이 떠 있는 동안 '허락 기다림'을 보인다.
- 모든 알림이 휴대폰 길(Claude 자체 알림 도구)도 탄다.

## Test scenarios

### T1. 2분 넘게 걸린 메인 차례가 답으로 끝나면 '끝' 알림

- **Setup**: 메인 차례, 끝난 이유 '답', 걸린 시간 3분 12초
- **Run**: 차례 끝
- **Expected**: 알림 문구에 '끝났어요'와 '3분 12초'가 들어 있다
- **Pass criterion**: 알림 1건, 문구가 같다

### T2. 2분 안에 끝난 차례는 알리지 않는다

- **Setup**: 메인 차례, 이유 '답', 걸린 시간 1분 59초
- **Run**: 차례 끝
- **Expected**: 알림 없음
- **Pass criterion**: 알림 0건

### T3. 오류로 끝나면 시간과 상관없이 알리고, 칸에 빨간 '멈춤 — 오류'를 보인다

- **Setup**: 메인 차례, 이유 '오류', 걸린 시간 5초
- **Run**: 차례 끝 → 칸 그리기 → 다음 차례 시작 → 칸 그리기
- **Expected**: '오류로 멈춤' 알림 1건. 칸에 빨간 '멈춤 — 오류'가 보이고, 다음 차례가 시작되면 사라진다
- **Pass criterion**: 알림 1건, 표시가 나타났다가 사라진다

### T4. 답을 거절하고 끝나면 '거절로 멈춤'

- **Setup**: 메인 차례, 이유 '거절'
- **Run**: 차례 끝 → 칸 그리기
- **Expected**: '거절로 멈춤' 알림과 칸 표시(T3과 같은 방식)
- **Pass criterion**: 알림 1건, 표시가 있다

### T5. 사용자가 멈춘 차례는 알리지 않는다

- **Setup**: 메인 차례, 이유 '사용자 멈춤', 걸린 시간 10분
- **Run**: 차례 끝 → 칸 그리기
- **Expected**: 알림 없음, 멈춤 줄 없음
- **Pass criterion**: 알림 0건, 표시 없음

### T6. 하위 에이전트의 차례가 끝나도 칸은 '일하는 중', 알림 없음

- **Setup**: 메인 차례 진행 중에, 에이전트 표시가 붙은 차례가 3분 만에 끝남
- **Run**: 에이전트 차례 끝 → 칸 그리기
- **Expected**: 칸은 '일하는 중' 그대로, 알림 없음
- **Pass criterion**: 상태 글이 바뀌지 않고 알림 0건

### T7. 허락 창이 뜨면 '허락 기다림'을 보이고 알린다, 도구가 끝나면 사라진다

- **Setup**: Bash `npm test`에 허락 창이 뜸
- **Run**: 허락 요청 → 칸 그리기 → 그 도구 끝 → 칸 그리기
- **Expected**: 빨간 '허락 기다림 — Bash: npm test'와 알림 1건, 도구가 끝나면 사라진다
- **Pass criterion**: 표시가 나타났다가 사라지고, 알림 1건

### T8. 허락을 거절해도 허락 기다림이 사라진다

- **Setup**: T7과 같은데 사용자가 거절
- **Run**: 허락 요청 → 거절된 도구 끝 → 칸 그리기
- **Expected**: '허락 기다림'이 없다
- **Pass criterion**: 표시 없음

### T9. 모든 알림이 Claude 자체 알림 도구로도 간다, 실패해도 다른 길은 그대로

- **Setup**: (가) 알림 도구 정상 (나) 알림 도구 없음 / 실패
- **Run**: 끝 알림 하나를 보낸다
- **Expected**: (가) 알림 도구에 200자 이하 한 줄 문구가 간다 (나) 시스템 알림과 토스트는 보내지고 칸이 멈추지 않는다
- **Pass criterion**: (가) 도구 호출 1건과 문구 길이 200자 이하 (나) 시스템 알림 1건, 칸 그리기 정상

### T10. 지금 있는 알림(답 기다림 · 시험 실패)도 같은 길로 간다

- **Setup**: 질문 도구 호출, 실패한 시험 실행
- **Run**: 각각
- **Expected**: 두 알림 모두 알림 도구에도 간다
- **Pass criterion**: 알림 도구 호출 2건

### T11. 지금 있는 시험이 계속 통과한다

- **Run**: 시험 전체를 돌린다
- **Pass criterion**: 기존 시험이 모두 통과한다

## How to run

```bash
cd marketplace/mods/scv-dashboard && claude plugin test .
```

## Pass criteria

- T1~T11 전부 통과
- 맥 앱·휴대폰 확인(PLAN의 Exit criteria)
