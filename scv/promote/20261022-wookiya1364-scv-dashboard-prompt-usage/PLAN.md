# SCV 칸 — 다음 할 일 입력창 넣기와 사용 한도

## Summary

'다음' 줄의 명령을 버튼 한 번으로 입력창에 넣는다. 차례가 끝났는데 입력창이 비어 있으면, 그 명령을 흐린 제안으로 띄워 Tab 키로 받게 한다. 5시간·7일 사용 한도가 몇 % 찼는지와 초기화 시각을 칸에 보여 주고, 90%를 넘으면 기간마다 한 번 알린다. 지금은 '명령 복사' 버튼뿐이고, 한도는 보이지 않는다(확인함).

## Goals / Non-Goals

- **Goals**
  - '입력창에 넣기' 버튼을 둔다.
    - 입력창이 비어 있으면 명령을 넣는다.
    - 사용자가 쓴 글이 있으면 지우지 않고 뒤에 붙인다.
    - 넣지 못하면 복사로 대신하고 '입력창에 못 넣어 복사함'이라고 보인다.
    - '명령 복사' 버튼은 그대로 남긴다.
  - Tab 제안: 메인 차례가 끝났고 다음 할 일이 명령이면 흐린 제안으로 띄운다. 제안은 입력창이 비어 있을 때만 보인다.
  - 사용 한도 줄: '5시간 72% · 17:40 초기화 · 7일 31%'처럼 보인다. 정보가 없으면 줄을 숨긴다.
  - 90% 알림: 5시간·7일 기간마다 한 번 알린다(초기화 시각 기준). 초기화된 뒤 다시 넘으면 다시 알린다.
- **Non-Goals**
  - 비용(금액) 표시
  - 한도에 맞춰 일을 멈추는 등의 자동 대응
  - 사용자가 쓴 입력을 지우는 것

## Approach Overview

- 버튼을 누르면 입력창의 지금 글을 읽어 비었는지 보고, 명령을 넣거나 뒤에 붙인다. 결과가 '못 넣음'이면 복사로 대신한다.
- 메인 차례가 끝나면 다음 할 일 명령을 제안으로 보낸다.
- 사용 한도는 새로 고칠 때 읽는다(형식 문서상 무료 호출). 이미 알린 기간은 모드 저장소에 기억한다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
planPromptFill   // (다음 명령, 입력창 글) → 넣을 글 · 방식
suggestNext      // (다음 할 일) → 제안 글 | 없음
flow(
  usageLine,     // (한도 목록, 지금) → 한 줄 | 없음
  usageAlerts,   // (한도 목록, 이미 알린 기간, 기준 90%) → 알릴 것 · 새 기억
)
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | 버튼·차례·새로 고침 | 버튼 누름, 차례 끝, 한도 읽기를 받는다 | 훅 이벤트 → 입력 | 부수효과 (입구) |
| 2 | planPromptFill | 입력창이 비었으면 넣고, 글이 있으면 뒤에 붙일 글을 만든다 | 다음 명령, 입력창 글 → 넣을 글 · 방식 | 순수 |
| 3 | suggestNext | 다음 할 일이 명령일 때만 제안 글을 만든다 | 다음 할 일 → 제안 / 없음 | 순수 |
| 4 | usageLine | 한도를 '5시간 72% · 17:40 초기화' 같은 한 줄로 만든다 | 한도 목록, 지금 → 한 줄 / 없음 | 순수 |
| 5 | usageAlerts | 90%를 넘은 기간 가운데 아직 안 알린 것만 고른다 | 한도, 알린 기간, 기준 → 알릴 것 · 새 기억 | 순수 |
| 6 | 넣기·제안·알리기·그리기 | 입력창에 넣거나 복사하고, 제안을 띄우고, 알리고, 칸을 그린다 | 결과 → 입력창 · 알림 · 화면 | 부수효과 (출구) |

- 부수효과 위치: 버튼·차례·새로 고침과 시계(입구), 입력창·클립보드·알림·그리기(출구)
- 재사용: nextAction(다음 할 일) · 지금의 알림 묶음 · 복사 버튼

## Guardrails

- 사용자가 입력창에 쓴 글은 지우지 않는다.
- 제안과 넣기는 보내지 않는다. 보내는 것은 늘 사용자가 Enter로 한다.
- 한도 알림은 기간마다 한 번만 보낸다.
- 지금 있는 시험은 계속 통과해야 하고, 버전은 올리지 않으며, 모드는 프로젝트 파일을 바꾸지 않는다.

## Exit criteria

- All TESTS.md scenarios pass
- 맥 앱에서 '입력창에 넣기'로 명령이 들어가는지(안 되면 복사로 대신하는지)와 한도 줄이 보이는지 사용자와 함께 확인한다(화면 사진 1장).

## Suggested path

1. 넣기 · 제안 · 한도 순수 함수 + 단위 시험 — `planPromptFill` `suggestNext` `usageLine` `usageAlerts`
2. '입력창에 넣기' 버튼과, 못 넣을 때 복사 — `planPromptFill` `넣기·제안·알리기·그리기`
3. 차례 끝 Tab 제안 — `suggestNext`
4. 한도 줄 · 90% 알림 — `usageLine` `usageAlerts`
5. 자동 시험 · 검사 · (물어본 뒤) 올리기 · 맥 앱에서 확인
