# Test Plan — SCV 칸 — 다음 할 일 입력창 넣기와 사용 한도

## Overview

다음을 검증한다.

- '입력창에 넣기'가 사용자 글을 지우지 않고 명령을 넣는다. 못 넣으면 복사로 대신한다.
- 메인 차례가 끝나면 다음 명령을 제안으로 띄운다.
- 사용 한도 줄을 보인다.
- 90% 알림을 기간마다 한 번만 보낸다.

## Test scenarios

### T1. 빈 입력창에 '입력창에 넣기'를 누르면 다음 명령이 들어간다

- **Setup**: 다음 할 일 `/scv:work <slug>`, 입력창은 비어 있다
- **Run**: '입력창에 넣기'를 누른다
- **Expected**: 입력창 글이 `/scv:work <slug>`가 된다
- **Pass criterion**: 넣은 글이 같다

### T2. 입력창에 글이 있으면 지우지 않고 뒤에 붙인다

- **Setup**: 입력창에 '이것도 봐 줘'
- **Run**: '입력창에 넣기'를 누른다
- **Expected**: '이것도 봐 줘'가 남고, 그 뒤에 명령이 붙는다
- **Pass criterion**: 원래 글이 그대로 있다

### T3. 못 넣으면 복사로 대신하고 그렇게 알린다

- **Setup**: 입력창 넣기 결과가 '못 넣음'
- **Run**: '입력창에 넣기'를 누른다
- **Expected**: 명령이 복사되고 '입력창에 못 넣어 복사함'이 보인다
- **Pass criterion**: 복사 1건과 안내 글

### T4. 메인 차례가 끝났고 다음 할 일이 명령이면 제안을 띄운다

- **Setup**: (가) 다음 할 일이 명령 (나) 명령이 없음 (다) 에이전트 차례가 끝남
- **Run**: 차례 끝
- **Expected**: (가) 명령을 제안으로 띄운다 (나) 띄우지 않는다 (다) 띄우지 않는다
- **Pass criterion**: 제안 호출이 (가)에서만 1건

### T5. 한도 줄을 한 줄로 보인다

- **Setup**: 5시간 72% · 초기화 17:40, 7일 31%
- **Run**: 칸을 그린다
- **Expected**: '5시간 72% · 17:40 초기화 · 7일 31%'
- **Pass criterion**: 글이 같다

### T6. 90%를 넘으면 한 번만 알리고, 초기화된 뒤 다시 넘으면 또 알린다

- **Setup**: 5시간 91%(초기화 17:40) → 다시 새로 고침 → 초기화 시각이 22:40으로 바뀐 뒤 92%
- **Run**: 세 번 새로 고친다
- **Expected**: 처음 1번 알림, 둘째는 알림 없음, 셋째에서 다시 1번
- **Pass criterion**: 알림이 모두 2건

### T7. 한도 정보가 없으면 줄이 없다

- **Setup**: 한도 목록이 비어 있다
- **Run**: 칸을 그린다
- **Expected**: 한도 줄이 없다
- **Pass criterion**: '5시간' 글자가 화면에 없다

### T8. '명령 복사' 버튼은 그대로 있다

- **Setup**: 다음 할 일이 명령
- **Run**: 칸을 그린다
- **Expected**: '입력창에 넣기'와 '명령 복사' 두 버튼이 있다
- **Pass criterion**: 두 버튼이 모두 있다

### T9. 지금 있는 시험이 계속 통과한다

- **Run**: 시험 전체를 돌린다
- **Pass criterion**: 기존 시험이 모두 통과한다

