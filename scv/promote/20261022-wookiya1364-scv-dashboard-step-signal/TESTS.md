# Test Plan — SCV 칸 — 진행률이 실제 작업 중에 움직이기

## Overview

Claude가 보내는 '단계 신호'로 진행률·단계 흐름·예상 완료 시간이 작업 중에 움직이는지 검증한다. 틀린 신호를 거절하는지, 지시 글이 진행 중 계획이 있을 때만 붙는지, 세션을 새로 열어도 이어지는지도 함께 본다.

## Test scenarios

### T1. 단계 끝 신호를 받으면 진행률이 1 오른다

- **Setup**: 단계 5개, 표시가 없는 진행 중 계획(in_progress)
- **Run**: 단계 신호 도구로 1번 '끝'을 보낸 뒤 칸을 그린다
- **Expected**: '1/5'가 보이고, 1번은 완료(초록), 2번은 진행(노랑) · '◀ 지금 여기'
- **Pass criterion**: 글자와 단계 상태가 기대와 같다

### T2. 계획서 표시와 신호를 합친다

- **Setup**: 계획서에는 1번 `[x]`, 신호로는 2번 '끝'
- **Run**: 칸을 그린다
- **Expected**: '2/5'가 보이고, 지금 단계는 3번
- **Pass criterion**: 합친 진행률이 2/5다

### T3. 틀린 신호는 거절하고 이유를 돌려준다

- **Setup**: 세 가지 — 없는 계획 이름 / 범위 밖 단계 번호(9) / 아직 시작 안 한 4번에 '막힘'
- **Run**: 하나씩 도구로 보낸다
- **Expected**: 도구 결과에 이유가 온다(예: '그런 계획 없음', '단계는 1~5', '막힘은 지금 단계(2번)에만'). 기록은 그대로다
- **Pass criterion**: 세 경우 모두 기록 변화가 없고 이유 글이 있다

### T3b. 한꺼번에 온 신호도 모두 남는다

- **Setup**: 단계 1·2·3 '끝' 신호를 동시에 보낸다
- **Run**: 저장된 기록을 본다
- **Expected**: 세 신호가 모두 있다
- **Pass criterion**: 기록의 단계가 1, 2, 3

### T4. 막힘 신호는 지금 단계를 빨강으로, 막힌 작업 카드에 이유를 보인다

- **Setup**: 1번 끝, 2번 '막힘'(메모 '시험 실패 — T3')
- **Run**: 칸을 그린다
- **Expected**: 2번 막힘(빨강), 막힌 작업 카드에 '시험 실패 — T3'
- **Pass criterion**: 상태와 이유가 보인다

### T5. 예상 완료 시간을 신호 시각으로 계산한다

- **Setup**: 단계 5개. 1번 0분, 2번 10분, 3번 20분에 '끝'
- **Run**: 칸을 그린다
- **Expected**: '예상 완료 시간: 약 20분 0초 남음 (추정 · 단계 2개 평균)'
- **Pass criterion**: 남은 시간과 '추정' 표시가 같다

### T5b. 단계 시간은 시작 신호부터 재고, 한꺼번에 보고한 끝은 시간으로 치지 않는다

- **Setup**: 1번 '진행' 0분 → '끝' 10분, 이어서 2·3번 '끝'을 몇 초 안에 보냄
- **Run**: 칸을 그린다
- **Expected**: '예상 완료 시간: 약 20분 0초 남음 (추정 · 단계 1개 평균)'
- **Pass criterion**: 몇 초짜리 간격이 평균에 들어가지 않는다

### T6. 진행 중 계획이 있을 때만 Claude 지시가 붙는다

- **Setup**: (가) promote에 계획이 있음 (나) 보관된 계획만 있음
- **Run**: Claude 지시 묶음을 만든다
- **Expected**: (가) 계획 이름·단계 수·부르는 법이 담긴 짧은 글이 붙는다 (나) 아무것도 붙지 않는다
- **Pass criterion**: 두 경우가 기대와 같다

### T7. 신호 도구는 허락 창을 띄우지 않는다

- **Setup**: 단계 신호 도구 호출의 허락 판단
- **Run**: 허락 판단을 묻는다
- **Expected**: '허용'. 다른 도구(Bash 등)의 판단은 모드가 바꾸지 않는다
- **Pass criterion**: 신호 도구만 허용된다

### T8. 세션을 새로 열어도 신호가 이어진다

- **Setup**: 신호 2개를 저장한 뒤 세션을 다시 시작한다
- **Run**: 칸을 그린다
- **Expected**: 같은 진행률(2/5)
- **Pass criterion**: 진행률이 같다

### T9. 신호도 표시도 없으면 지금처럼 '(추정)'

- **Setup**: 표시와 신호가 없는 진행 중 계획
- **Run**: 칸을 그린다
- **Expected**: '단계 흐름 (추정)', '0/5', '아직 추정 불가'
- **Pass criterion**: 지금과 같은 화면이다

### T10. 지금 있는 시험 30개가 계속 통과한다

- **Run**: 시험 전체를 돌린다
- **Pass criterion**: 기존 30개가 통과한다

## How to run

```bash
cd marketplace/mods/scv-dashboard && claude plugin test .
```

## Pass criteria

- T1~T10 전부 통과
