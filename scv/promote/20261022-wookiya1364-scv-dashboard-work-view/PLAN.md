# SCV 칸 — 자리 비운 사이 요약과 에이전트별 줄

## Summary

마지막으로 메시지를 보낸 뒤 생긴 일을 세 줄 안으로 묶어 보여 준다. 끝난 단계, 돌린 시험과 결과, 기다리는 질문·허락, 멈춤이 들어간다. 여러 에이전트가 동시에 일할 때는 에이전트마다 지금 하는 일을 한 줄씩 보여 준다. 지금 '진행 중' 칸은 도구를 하나만 기억한다. 그래서 동시에 작업하면 마지막에 시작한 것만 보인다(확인함).

## Goals / Non-Goals

- **Goals**
  - '그 사이' 카드: 기준은 마지막으로 메시지를 보낸 시각이다.
    - 1줄: 끝난 단계 수와 이름 (예: '단계 2개 끝 — 신호 함수, 도구 등록')
    - 2줄: 시험 (예: '시험 3번 — 실패 1번 뒤 통과')
    - 3줄: 기다리는 것 (예: '질문 1개 기다림' / '허락 기다림 — Bash' / '오류로 멈춤')
    - 메시지를 보낸 뒤 지난 시간도 함께 보인다. 아무 일도 없으면 카드를 숨긴다. 다음 메시지를 보내면 새로 시작한다.
  - 에이전트별 줄: 진행 중 카드에 메인 줄과 에이전트마다 한 줄을 둔다(이름이나 설명 · 지금 도구 · 대상 · 지난 시간). 5줄까지 보이고 넘으면 '+N개 더'로 줄인다. 에이전트가 끝나면 그 줄은 사라진다.
  - 하위 에이전트 안의 도구 호출도 칸에 보인다(지난 계획의 미결 항목 풀기).
- **Non-Goals**
  - 에이전트의 전체 기록 보기, 다른 세션 보기
  - 메시지를 보내기 전에 일어난 일

## Approach Overview

- 메시지를 보낼 때 시각을 적는다. 단계 끝(step-signal 계획의 기록, 계획서 표시가 바뀐 시각), 시험 실행(시각 있음), 기다림·멈춤(alerts 계획) 가운데 그 시각 뒤의 것만 골라 요약한다.
- 도구 호출과 차례에 붙은 에이전트 표시로, 에이전트별 '지금 도구'를 따로 기억한다. 이름은 에이전트 시작 정보(설명)에서 가져오고, 없으면 '에이전트 1'처럼 번호를 붙인다.

## 순수함수 · 파이프라인 (Pure functions & pipeline)

```
flow(
  eventsSince,      // (사건 기록, 기준 시각) → 그 뒤 사건
  summarizeAway,    // (그 뒤 사건, 지금) → 세 줄 | 없음
)
applyAgentEvent     // (에이전트 목록, 이벤트) → 에이전트 목록
agentLines          // (에이전트 목록, 지금, 최대 5) → 줄들 + '+N개 더'
```

| # | 단계 | 하는 일 | 받는 값 → 돌려주는 값 | 순수/부수효과 |
|---|---|---|---|---|
| 1 | 메시지·도구·차례 관찰 | 메시지를 보낸 시각과 에이전트별 도구 시작·끝을 지켜본다 | 훅 이벤트 → 기록 | 부수효과 (입구) |
| 2 | eventsSince | 기준 시각 뒤에 생긴 일만 고른다 | 기록, 기준 → 그 뒤 일 | 순수 |
| 3 | summarizeAway | 그 뒤 일을 세 줄 안의 쉬운 말로 묶는다 | 그 뒤 일, 지금 → 요약 / 없음 | 순수 |
| 4 | applyAgentEvent | 에이전트가 시작하거나, 도구를 쓰거나, 끝날 때 목록을 고친다 | 목록, 이벤트 → 새 목록 | 순수 |
| 5 | agentLines | 에이전트마다 한 줄을 만들고, 5개가 넘으면 '+N개 더'로 줄인다 | 목록, 지금 → 줄들 | 순수 |
| 6 | 그리기 | 그 사이 카드와 진행 중 카드를 그린다 | 요약 · 줄 → 화면 | 부수효과 (출구) |

- 부수효과 위치: 메시지·도구·차례 훅과 시계(입구), 그리기(출구)
- 재사용: describeTool · formatDuration · 시험 실행 기록 · step-signal 계획의 단계 기록

## Guardrails

- 기준 시각보다 앞선 일은 요약에 넣지 않는다.
- 비밀이 섞일 수 있는 긴 명령 원문은 요약에 넣지 않는다. 설명이나 앞부분만 쓴다.
- 모드는 프로젝트 파일을 바꾸지 않고, 지금 있는 시험은 계속 통과해야 하며, 버전은 올리지 않는다.

## Exit criteria

- All TESTS.md scenarios pass
- 맥 앱에서 메시지를 보내고 자리를 비웠다가 돌아와 '그 사이' 카드가 맞는지 사용자와 함께 확인한다(화면 사진 1장).

## Suggested path

1. 그 사이 요약 · 에이전트 목록 순수 함수 + 단위 시험 — `eventsSince` `summarizeAway` `applyAgentEvent` `agentLines`
2. 메시지 시각 기록, 그 사이 카드 그리기 — `메시지·도구·차례 관찰` `그리기`
3. 에이전트별 도구 기억, 진행 중 카드에 줄 — `applyAgentEvent` `agentLines`
4. 자동 시험 · 검사 · (물어본 뒤) 올리기 · 맥 앱에서 확인

## Risks / Open Questions

- 에이전트 이름을 시작 정보와 짝짓는 방법은 구현할 때 확인한다. 짝을 못 찾으면 '에이전트 1'처럼 번호로 보인다.
- 끝난 단계는 step-signal 계획의 신호나 계획서 표시가 있어야 정확하다.
