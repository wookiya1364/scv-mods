# scv-dashboard 0.2.7

거울 세션에서 실수로 대화를 쳐도, 작업과 무관한 다른 Claude가 받지 않습니다.

## 바뀐 것

- 0.2.6 까지는 거울을 켠 세션(다른 기기 앱에서 SCV 칸만 보려고 연 세션)에 글을 치면, 그 세션의 Claude가 받아 답했습니다. 그 Claude는 작업 세션의 대화를 모르는 별개의 Claude입니다.
- 이제 거울이 켜진 세션에 친 글은 Claude에게 가지 않습니다. 대신 이렇게 알려 줍니다: "이 세션은 <작업 세션> 의 SCV 칸만 보여 주는 거울입니다 — 대화는 작업 세션 창에서 하세요. 이 세션을 다시 쓰려면 /scv-mirror stop".
- `/scv-mirror stop` 같은 슬래시 명령은 그대로 됩니다. 거울을 끄면 다시 대화할 수 있습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
