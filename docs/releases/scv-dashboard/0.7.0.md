# scv-dashboard 0.7.0

SCV 창에 언어 칸이 생겼고, 대화를 비운 직후 할 일 목록이 다시 뜹니다.

## 바뀐 것

- **언어 칸이 생겼습니다.** 위쪽 칸의 맨 아래(자동 비우기 줄 아래)에서 한국어 · English · 日本語 중에 고르거나, 그 밖의 언어는 이름을 적습니다. 고르면 프로젝트의 `scv/scv_settings.json` 의 `SCV_LANG` 하나만 바뀌고, 창의 글 전부(이름표 · 단추 · 안내 줄 · 알림)가 그 언어로 보입니다. 같은 설정이 Claude 가 답하는 언어도 정합니다.
- **그 밖의 언어는 한 번 번역해 둡니다.** 이름을 적으면 이 세션의 Claude 가 창의 글을 한 번 번역해 프로젝트의 `scv/dashboard-lang/<이름>.json` 에 저장하고, 그 뒤로는 저장한 번역으로 보입니다. 번역이 생기기 전과 번역에 없는 글은 영어로 보입니다.
- **비운 직후 할 일 목록이 다시 뜹니다.** 창이 대화를 자동으로 비우면 앱의 할 일 목록이 사라졌습니다. 이제 끝나지 않은 할 일이 있으면, 창이 직전 대화를 보인 뒤 짧은 글 한 줄을 보내고 Claude 가 그 턴의 첫 동작으로 비우기 전 목록을 다시 띄웁니다. 따로 할 일은 없습니다. 목록의 내용은 Claude 만 읽는 안내에 실리므로 화면에는 세 줄짜리 글만 보입니다.

## 알아 둘 것

- 사용자가 쓴 글(계획 제목 · 단계 이름 · 기어 이름 · 브랜치 이름)은 번역하지 않습니다. 창이 Claude 에게 보내는 글도 번역하지 않습니다.
- 설정 파일이 없는 폴더(SCV 프로젝트가 아닌 곳)에는 언어 칸이 없습니다. 거울 화면에서 고르면 작업 세션이 자기 프로젝트의 설정 파일에 쓰고, 저장한 번역은 거울로 보내지 않으므로 그 밖의 언어는 거울에서 영어로 보입니다.
- Claude Code 자체의 언어 설정이 고정된 컴퓨터에서는 `SCV_LANG` 을 바꿔도 답의 언어가 바뀌지 않을 수 있습니다(창의 글은 바뀝니다).
- 목록은 같은 순간에 뜨지 않습니다. 앱은 Claude 가 턴 안에서 목록 도구를 부를 때만 목록을 그리기 때문입니다 — 창이 턴 밖에서 직접 부른 두 번은 호출은 성공했지만 화면에 그려지지 않았습니다. 그래서 비울 때마다(끝나지 않은 할 일이 있을 때) 짧은 턴이 하나 더 듭니다.
- 걸리는 시간은 SCV 포장의 판에 달렸습니다. scv-claude-code 0.105.2 부터는 창이 보낸 글을 자동으로 온 글로 알아봐 약 5초로 예상합니다(추정 — 턴 시작 검사 1.3초는 측정, 나머지는 한 번의 실험에서 나눈 값). 그 전 판에서는 사람이 친 글로 처리되어 약 10초가 걸리고 도움말 호출이 붙습니다.
- 목록이 없거나 모두 끝났을 때, 비우기가 확인되지 않았을 때, 사람이 직접 비웠을 때, 거울 세션에서는 글을 보내지 않습니다. 목록을 통째로 보내는 도구(`mcp__ccd_turn__update_plan` · `TodoWrite`)로 만든 목록만 다시 띄웁니다.
- 확인은 모드 시험 291개로 했습니다(언어 17개 · 목록 다시 띄우기 9개가 새 시험). 실제 앱에서 언어 칸을 누르는 것, 그 밖의 언어 번역에 걸리는 시간, 실제로 비운 뒤 목록이 뜨는 것과 걸리는 시간, 원격 화면의 모습은 아직 보지 못했습니다.
