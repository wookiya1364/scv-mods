# scv-dashboard 0.3.0

SCV 창 위쪽에 컨텍스트 · 사용 한도 · 묻기 방식 · 기어가 항상 보입니다. 묻기 방식은 창에서 눌러 바꾸고, 기어는 창에서 보고 씁니다.

## 바뀐 것

- **위 칸.** 컨텍스트 · 사용 한도가 맨 위에 나옵니다. 전에는 '진행 중' 칸 안에 있어서 진행 중인 계획이 없으면 보이지 않았습니다.
- **묻기 방식 칸.** 지금 값(전부 묻기 | 처음 · 끝에만 묻기)과 그 뜻이 보이고, 버튼을 누르면 바로 바뀝니다(다음 메시지부터 적용, 턴을 쓰지 않음). SCV 설치를 찾지 못하면 바꾸는 명령을 입력창에 넣어 줍니다.
- **기어 칸.** 기어마다 이름 · 받는 값 → 돌려주는 값 · 하는 일 · 인자가 보입니다. [쓰기]를 누르면 그 기어를 돌리는 명령이 입력창에 들어가고, 보내면 Claude 가 필요한 값을 선택 창으로 묻습니다(SCV 0.102.0+).
- **바로 실행.** 흐름 전체에 부작용이 없는 기어(표시 `pure`)는 창에서 바로 돌립니다. 30초 제한이 있고, 받는 값이 있으면 입력 칸에 적습니다 — 적은 글은 표준 입력으로만 갑니다. 결과는 그 칸에 나옵니다. 인자는 기본값을 씁니다.
- **확인 기다림.** 밖으로 나가는 단계 앞에서 멈춘 기어 실행이 있으면 기어 칸에 알립니다.
- **더 보기.** 진행률 · 다음 할 일 · 진행 중 · 뒤에서 도는 일 · 시험 결과 · 드림 · 변경 이력은 '더 보기' 안에 접힙니다. 접힘 상태는 다음 세션에도 남습니다. 막힌 작업은 접지 않고 위에 보입니다.

## 알아 둘 것

- 처음에는 '더 보기'가 접혀 있습니다. 한 번 펼치면 그대로 남습니다.
- [바로 실행]은 SCV 0.102.0 이 만든 기어 목록(표시 칸이 있는 것)에서만 붙습니다. 예전 목록이면 세션을 시작할 때 SCV 에 목록을 한 번 다시 쓰게 합니다.
- 휴대폰 화면에는 글 입력 칸이 없어, 받는 값이 있는 기어의 [바로 실행]은 나오지 않습니다. [쓰기]는 어디서나 나옵니다.
- 보기 전용(미러) 세션에서는 값만 보이고 버튼은 없습니다.
