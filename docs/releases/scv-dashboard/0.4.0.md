# scv-dashboard 0.4.0

기어 줄의 [실행]을 누르면 바로 돕니다. SCV 창이 기어를 직접 돌리고, Claude 를 거치지 않습니다.

## 바뀐 것

- **기어 줄의 [실행]을 누르면 바로 돕니다.** 접힌 기어 줄에 보이는 버튼이 [실행]입니다(전에는 [쓰기]였고, 누르면 채팅 명령이 입력창에 들어갔습니다). 입력창 위 줄의 [사용함]도 같습니다. 전에는 둘 다 Claude 가 한 턴을 통째로 돌아야 했습니다(큰 세션 하나에서 잰 값: 한 번에 3.6분, 모델 호출 10번). 이제 창이 기어를 직접 돌려서 모델 호출이 없습니다. 이 컴퓨터에만 영향을 주는 기어까지 돌립니다(전에는 영향이 없는 기어만, 펼친 칸의 [바로 실행]으로, 30초까지).
- **값이 필요 없는 기어는 누르는 즉시 돕니다.** 입력창의 글은 건드리지 않고, 보내는 것도 없습니다.
- **값은 창에서 정합니다.** 값이 필요한 기어는 [실행]을 누르면 그 줄이 펼쳐지며 값 칸이 나옵니다. 고르는 값은 버튼으로 나오고(예: 돌릴 곳 `mac` · `linux`), 지금 값이 미리 골라져 있습니다. 숫자나 글처럼 적어야 하는 값과 기어가 읽을 자료는 입력 칸에 적습니다. 다 정하고 [이 값으로 실행]을 누릅니다.
- **오래 걸려도 됩니다.** 시간 제한이 없습니다. 도는 동안 기어 줄에 마지막 출력 한 줄과 걸린 시간이 보이고, [멈춤]으로 멈출 수 있습니다. 30초 넘게 걸린 실행은 끝났을 때 알림이 한 번 갑니다. 결과(끝난 모양과 마지막 줄들)는 기어 줄에 남습니다.
- **밖으로 나가는 기어는 먼저 묻습니다.** 올리기 · 네트워크 · 지우기 같은 단계가 든 기어는 어느 단계가 밖으로 나가는지 보여 주고 [실행] · [취소]를 기다립니다. [취소]면 아무것도 돌지 않습니다. [실행]이면 SCV 가 그 답을 적어 둔 뒤에만 그 단계가 돕니다.
- **[결과를 대화에 붙이기].** 창에서 돌린 결과를 Claude 가 알아야 할 때만 누르세요. 결과가 입력창에 들어가고, 보내지는 않습니다.
- **Claude 가 해야 하는 기어는 줄의 버튼이 [대화로]입니다.** Claude 가 판단하는 단계가 든 기어가 그렇습니다. 누르면 전의 [쓰기]처럼 기어 명령이 입력창에 들어갑니다. 창이 돌릴 수 있는 기어도 Claude 에게 시키고 싶으면, 줄을 펼쳐 [Claude 에게 시키기]를 누르거나 값 칸에서 [Claude 에게 맡기기]를 누르세요.

## 알아 둘 것

- [사용함]을 누르면 SCV 창이 열리고, 값 정하기 · 확인 · 결과가 그 창의 기어 줄에 나옵니다. 누르지 않고 그대로 보내면 전처럼 그 기어를 쓰라는 한 줄이 붙어 Claude 에게 갑니다.
- 적은 값과 자료는 기어에 값으로만 전해집니다. 명령으로 읽히지 않습니다(따옴표 · `;` 가 들어 있어도 글자 그대로).
- 도는 동안에는 그 줄의 [실행]이 사라지고 펼친 칸에 [멈춤]이 있습니다. 값 칸이나 확인이 열려 있는 동안에도 줄의 [실행]은 사라집니다 — 그 칸의 버튼을 누르세요.
- 휴대폰 화면처럼 입력 칸이 없는 곳에서는, 적어야 하는 값이 있는 기어는 대화로 넘어갑니다. 버튼으로 고르는 값만 있으면 그 화면에서도 돌립니다.
- 창이 물은 것과 다른 단계에서 기어가 멈추면 그 단계를 보여 주고 한 번 더 묻습니다. 그때 [취소]를 누르면 멈춘 실행이 '확인 기다림'에 남습니다.
- 세션이 끝나면 돌던 기어도 멈춥니다. [멈춤]으로 멈춘 실행은 SCV 의 임시 기록 폴더에 흔적이 남을 수 있습니다.
- 도는 동안의 마지막 출력 줄은 3초마다 새로 읽습니다.
- 창에서 돌리려면 SCV 0.102.0 이상이 필요합니다. 그보다 예전이면 [실행]을 눌러도 전처럼 대화로 가고, 그 뒤로 그 줄의 버튼은 [대화로]로 바뀝니다.
- 확인은 시험 11개와, 연습용 프로젝트에서 실제 SCV 명령을 돌려 본 것으로 했습니다(값 넘기기 · 밖으로 나가는 단계의 확인 · 멈춤). 앱 화면에서의 모습은 아직 보지 못했습니다.
