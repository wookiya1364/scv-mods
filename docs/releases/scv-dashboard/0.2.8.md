# scv-dashboard 0.2.8

다른 기기에서 거울 세션을 여는 일이 링크 한 번과 Enter로 줄어듭니다.

## 바뀐 것

- 0.2.7 까지는 다른 기기 앱에서 새 세션을 직접 만들고 `/scv-mirror <주소>`를 입력해야 했습니다.
- 이제 원격 창에서 `/scv-dashboard`를 치면 응답에 **거울 세션 열기** 링크가 나옵니다. 그 기기에서 누르면 Claude 앱이 새 세션을 열고 입력창에 `/scv-mirror <주소>`를 채웁니다. Enter만 누르면 됩니다.
- 링크는 Claude Desktop 공식 링크(`claude://code/new?q=…`)라 입력창을 채우기만 하고 혼자 보내지 않습니다. 링크가 눌리지 않는 화면에서는 같은 응답의 명령 줄을 그대로 쓰면 됩니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
