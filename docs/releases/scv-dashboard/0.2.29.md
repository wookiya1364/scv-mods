# scv-dashboard 0.2.29

단계 노드를 누르면 끝난 단계는 끝났다는 증거를, 진행 중인 단계는 지금 실제로 무엇이 돌고 있는지 보여 줍니다. 증거 없는 '끝'은 받지 않습니다.

## 바뀐 것

- 단계 알림(scv_step)의 '끝'에는 증거가 있어야 합니다: 이 단계가 만들거나 바꾼 프로젝트 안 파일(화면 · 결과 파일, `evidence`) 또는 결과를 보여 주는 명령 출력 발췌(`output`). 증거가 없거나, 파일이 없거나, 프로젝트 밖 파일이거나, 단계 시작 전에 생긴 옛 파일이면 거절하고 무엇을 보내면 되는지 알려 줍니다.
- 끝난 단계를 누르면 '증거' 칸이 열립니다 — 작은 그림(90 KB 이하)은 그림으로, 글 파일은 앞부분, 명령 출력은 그대로, 파일마다 '열기' 버튼.
- 진행 중인 단계를 누르면 '지금 진행' 칸이 열립니다 — 시작할 때 알린 로그 파일(`log`)의 최근 줄과 진행률 막대('3/10' · '45%'를 읽음), 진행 화면 주소(`url`)를 여는 버튼.
- "지금 하는 일" 한 줄을 없앴습니다. 뒤에서 도는 일과 그 진행률, 최근 끝난 일은 그대로 보입니다.

## 알아 둘 것

- 진행 화면 주소는 버튼으로 열기만 하고, 대시보드가 그 페이지를 읽지 않습니다.
- 90 KB 가 넘는 그림은 칸 안에 그리지 않고 '열기' 버튼만 둡니다(데스크톱 칸이 그릴 수 있는 크기 한도).
- 로그를 알리지 않은 진행 중 단계는 "진행 출처 없음"으로 보입니다.
- 이 버전 이전에 끝난 단계는 증거가 없어 "증거 없음"으로 보입니다.

## 받는 법

`/scv:update` (SCV 0.94.1 이상) 또는 `/scv:mods`. 그다음 새 세션. 증거를 싣는 규칙은 SCV 0.95.0 의 작업 규약에도 들어 있습니다.
