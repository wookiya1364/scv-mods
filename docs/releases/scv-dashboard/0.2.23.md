# scv-dashboard 0.2.23

보관한 계획이 64개를 넘는 프로젝트에서도 SCV 칸이 그려집니다.

## 바뀐 것

- 계획 고르기 목록에는 Claude Code 화면 규칙상 64개까지만 들어갑니다. 예전에는 이보다 많으면 칸 전체가 그려지지 않고 "Nothing to show yet" 만 보였습니다. 보관한 계획이 113개인 프로젝트가 그런 경우였습니다.
- 이제 목록에는 진행 중인 계획을 먼저 넣고, 남은 자리는 최근에 보관한 계획으로 채워 64개까지 보입니다. 지금 칸에 보이는 계획은 늘 목록에 남습니다.
