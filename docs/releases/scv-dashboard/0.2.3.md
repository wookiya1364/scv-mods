# scv-dashboard 0.2.3

거울을 잘못 걸어도 보던 화면이 꺼지지 않게 했습니다. 자기 주소를 넣으면 무엇이 잘못됐는지 한국어로 알려 줍니다.

## 바뀐 것

- `/scv-mirror` 에 이 세션 자신의 주소를 넣으면, 이제 아무것도 보내지 않고 "이건 이 세션 자신의 주소입니다 — …보고 싶은 다른 세션에서 /scv-dashboard 를 쳐서 나온 주소를 넣으세요" 라고 알려 줍니다. 0.2.2 까지는 영어 오류("…is this session itself…")가 났습니다.
- 거울 요청이 실패해도(자기 주소, 꺼진 세션 등) 걸려 있던 거울은 그대로 둡니다. 0.2.2 까지는 실패 한 번에 거울이 꺼져, 칸이 '계획 없음' 으로 돌아갔습니다.
- `/scv-dashboard` 안내를 "이 세션을 다른 기기 앱에서 보려면, 그 기기에서 연 다른 세션에서: /scv-mirror <주소>" 로 바꿨습니다.

## 받는 법

양쪽 컴퓨터 모두에서 `/scv:mods` (SCV 0.70.0 이상). 또는 셸에서 `claude plugin marketplace update scv-mods` 다음 `claude plugin update scv-dashboard@scv-mods`. 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
