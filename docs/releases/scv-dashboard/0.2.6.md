# scv-dashboard 0.2.6

단계 흐름에서 '하는 일'이 "찾지 못했습니다"로 비는 일이 없어집니다.

## 바뀐 것

- 0.2.5 까지는 표와 잇는 이름도, 줄 끝 한 줄도 없는 단계(SCV 0.70.3 이전에 쓴 계획서의 "자동 시험 · 검사 · 올리기" 같은 단계)가 "계획서 파이프라인 표에서 이 단계가 하는 일을 찾지 못했습니다"로 나왔습니다.
- 이제 그런 단계는 단계 줄 자체를 '하는 일'로 보여 줍니다. 예: `• 자동 시험 · 검사 · (물어본 뒤) 올리기 · 맥 앱에서 확인`.
- 표와 이어진 단계, 줄 끝 한 줄이 있는 단계는 그대로입니다. 더 자세히 보이려면 계획서 단계 줄 끝에 ` — <하는 일 한 줄>`을 적습니다(SCV 0.70.4 는 빠진 줄을 작업 시작 때 알려 줍니다).

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
