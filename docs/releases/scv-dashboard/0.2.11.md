# scv-dashboard 0.2.11

다른 기기의 거울 칸에서 드림 '보고서 열기'를 누르면, 그 기기에서 보고서가 열립니다.

## 바뀐 것

- 0.2.10 까지 거울 칸의 '보고서 열기'는 작업 세션에 "열어 달라"는 메시지를 보냈습니다. 그래서 두 가지 문제가 있었습니다.
  - 거울 세션이 자동 모드면 그 메시지가 판정을 받지 못해 막혔습니다(칸에 빨간 오류).
  - 보내지더라도 보고서는 작업 세션이 도는 컴퓨터에서 열렸습니다.
- 이제 작업 세션이 보고서 내용(드림 보고서 HTML, 수 KB)을 칸 상태와 함께 보냅니다. 거울 칸의 '보고서 열기'는 아무것도 보내지 않고, 받은 내용을 그 기기의 임시 파일로 써서 엽니다(리눅스 `xdg-open`, 맥 `open`).
- 작업 세션이 아직 보고서를 보내지 않았으면 칸에 그렇다고 적습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션. 작업 세션과 거울 세션 양쪽 모두 0.2.11 이어야 합니다.
