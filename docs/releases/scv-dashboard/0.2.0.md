# scv-dashboard 0.2.0

다른 컴퓨터에서도 SCV 칸을 볼 수 있게 하는 '거울 칸'이 들어 있습니다. Remote Control 로 연 세션 화면(다른 컴퓨터의 데스크톱 앱 · claude.ai · 휴대폰)에는 Claude Code 가 확장 기능 칸을 그리지 않습니다. 그래서 그 컴퓨터의 앱이 직접 연 세션 하나가 작업 세션의 상태를 받아 자기 칸에 그립니다.

## 들어 있는 것

- `/scv-mirror <주소>`: 이 세션의 SCV 칸이 그 주소의 작업 세션을 보여 줍니다. 작업 세션은 상태가 바뀔 때마다, 그대로여도 30초마다 보냅니다. 칸 맨 위에 '거울: <주소> · n초 전 받음'이 나옵니다.
- `/scv-mirror`(주소 없이): 무엇을 거울로 보고 있는지, 마지막으로 언제 받았는지, 그 계획의 진행률을 한 줄로 알려 줍니다. `/scv-mirror stop`: 거울을 끄고 이 폴더의 계획으로 돌아갑니다.
- `/scv-dashboard` 의 답이 이 세션의 거울 주소를 알려 줍니다. Remote Control 이 켜져 있으면 그 번호(다른 컴퓨터에서 닿음), 꺼져 있으면 이 컴퓨터 안에서만 닿는 번호입니다. Remote Control 로 보는 화면에도 이 답은 보이므로, 다른 컴퓨터에서 작업 세션에 `/scv-dashboard` 를 쳐서 주소를 얻을 수 있습니다.
- 두 세션이 주고받는 메시지는 SCV 가 받아서 처리하고, 어느 쪽 Claude 에도 전달되지 않습니다(대화에 나타나지 않고 토큰도 쓰지 않습니다). 다른 메시지는 그대로 Claude 에게 갑니다.
- 원격 앱이 세션에 붙었다고 알려 오면 칸을 다시 엽니다(지금의 Remote Control 앱은 알려 오지 않습니다).

## 쓰는 법

1. 작업 세션(터미널이든 앱이든)에서 `/scv-dashboard` — 답에 나온 `/scv-mirror session_…` 을 복사합니다.
2. 다른 컴퓨터의 Claude 데스크톱 앱에서 그 컴퓨터의 아무 폴더로 세션을 하나 열고(Code 탭 → 이 컴퓨터), 복사한 명령을 붙여 넣습니다.
3. 그 세션의 SCV 칸이 작업 세션을 보여 줍니다. 작업은 지금처럼 Remote Control 로 연 작업 세션에서 하고, 칸은 옆 세션에서 봅니다.

## 아직 확인하지 않은 것

한 컴퓨터 안에서 두 세션 사이(Remote Control 번호를 거치는 길 포함)는 실제로 확인했습니다. 다른 컴퓨터 사이에서 받는 것과, 다른 컴퓨터 앱의 칸에 그려지는 모습은 아직 보지 못했습니다. 거울을 보는 세션은 Remote Control 이 켜져 있어야 다른 컴퓨터의 작업 세션이 답을 보낼 수 있습니다.

## 받는 법

양쪽 컴퓨터 모두에서 `/scv:mods` (SCV 0.70.0 이상). 또는 셸에서 `claude plugin marketplace update scv-mods` 다음 `claude plugin update scv-dashboard@scv-mods`. 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
