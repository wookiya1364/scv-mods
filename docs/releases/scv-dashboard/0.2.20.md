# scv-dashboard 0.2.20

The dashboard now shows a plan that is on hold. It also shows when that plan will resume and which plan it will return to. Use it with SCV 0.86.0 or later.

## What changed

- A plan whose status is `paused` (on hold) is shown in the list with the label "보류" ("on hold").
  - If another plan has to finish first, the label also gives that plan's name: "보류 · <plan> 끝나면 재개" ("on hold · resumes when <plan> finishes").
  - A plan on hold appears in the list right after the plans in progress.
- A plan that will return to an earlier plan when it finishes shows "끝나면 돌아갈 계획: <plan>" ("plan to return to when done: <plan>").
- The next-action line for a plan on hold now reads "보류 중 — 먼저 할 계획이 끝나면 이어서 함" ("on hold — continues once the plan that goes first finishes").

## How to get it

Run `/scv:mods` (SCV 0.70.0 or later). Then run `/reload-plugins` in the open session, or start a new session.
