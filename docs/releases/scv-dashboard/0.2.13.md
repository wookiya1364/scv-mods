# scv-dashboard 0.2.13

거울을 새로 걸면 처음부터 작업 세션의 지금 계획이 보입니다. 다시 걸지 않아도 됩니다.

## 바뀐 것

- 0.2.12 까지는 다른 기기에서 `/scv-mirror <주소>` 를 처음 걸면 예전 계획이 보일 때가 있었습니다. 작업 세션의 상태가 오기 전까지는 그 기기 자기 폴더의 계획이나 예전에 받은 계획을 그대로 그렸기 때문입니다. 그래서 거울을 껐다가 다시 걸어야 제대로 보였습니다.
- 이제 거울을 새로 걸면 상태가 올 때까지 `상태를 기다리는 중` 만 보이고, 예전에 고른 계획도 지웁니다. 같은 작업 세션에 다시 걸어도 마찬가지입니다.
- 작업 세션은 상태를 보낼 때 보낸 시각을 함께 보냅니다. 거울은 이미 받은 것보다 먼저 보낸 상태가 늦게 도착하면 버리므로, 옛 계획이 새 계획을 덮지 않습니다. 보낸 시각이 없는 상태(0.2.12 이하가 보낸 것)는 그대로 받습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션. 작업 세션과 거울 세션 양쪽 모두 0.2.13 이어야 합니다.
