# scv-dashboard 0.2.2

거울을 쓸 때 데스크톱 앱에 '다른 세션' 줄이 덜 쌓이게 했습니다. 거울 칸의 '입력창에 넣기'와 '보고서 열기'는 이제 원래 작업 세션 쪽에서 실행됩니다.

## 바뀐 것

- 0.2.1 까지는 작업 세션이 바뀐 게 없어도 30초마다 상태를 보냈고, 보기 세션은 1분 동안 소식이 없으면 다시 요청했습니다. 다른 컴퓨터에서 온 메시지마다 앱이 '다음 발신자로부터 메시지 수신 · 다른 세션' 줄을 그리기 때문에, 가만히 있어도 줄이 계속 늘었습니다.
- 이제 작업 세션은 상태가 바뀌었을 때만, 최소 10초 간격으로 보냅니다. 보기 세션은 10분 동안 아무것도 못 받았을 때만 다시 요청합니다. 쉬는 동안에는 줄이 거의 생기지 않습니다. 다만 앱이 그리는 줄이라 0개가 되지는 않습니다.
- 거울 칸에서 '입력창에 넣기'를 누르면, 작업 세션이 그 계획의 다음 명령을 자기 입력창에 넣습니다. 넣기만 하고 실행하지는 않습니다. '보고서 열기'는 작업 세션 컴퓨터에서 보고서를 엽니다. 넣을 명령은 메시지에 실려 오지 않고 작업 세션이 직접 계산하며, 거울을 걸어 온 세션의 요청만 받습니다.
- 쉬는 동안 거울 칸의 '몇 분 전 받음'이 계속 늘어나는 것은 바뀐 게 없다는 뜻입니다.

## 받는 법

양쪽 컴퓨터 모두에서 `/scv:mods` (SCV 0.70.0 이상). 또는 셸에서 `claude plugin marketplace update scv-mods` 다음 `claude plugin update scv-dashboard@scv-mods`. 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션. 두 쪽이 모두 0.2.2 여야 버튼 넘기기가 동작합니다.
