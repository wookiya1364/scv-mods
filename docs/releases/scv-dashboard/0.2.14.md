# scv-dashboard 0.2.14

다른 기기에서 처음 건 거울이 `상태를 기다리는 중` 에 멈추지 않습니다. 두 번 걸지 않아도 됩니다.

## 바뀐 것

- 새로 연 세션은 Remote Control 이 켜져 있어도 그 주소가 조금 늦게 적힙니다. 그 사이에 `/scv-mirror <주소>` 를 치면 요청이 이 컴퓨터 안에서만 닿는 주소로 나가, 다른 컴퓨터의 작업 세션은 답할 수 없었습니다. 0.2.12 까지는 그동안 그 기기 폴더의 예전 계획이 보였고, 0.2.13 에서는 `상태를 기다리는 중` 에 멈췄습니다. 두 번째로 걸면 그때는 주소가 적혀 있어 제대로 보였습니다.
- 이제 상태를 기다리는 동안 이 세션의 주소가 바뀌면, 새 주소로 저절로 다시 요청합니다. 상태를 받은 뒤에는 지금처럼 10분 동안 소식이 없을 때만 다시 묻습니다.
- 주소를 아직 찾지 못했을 때의 안내가 "Remote Control이 꺼져 있어" 대신 "주소를 아직 찾지 못해 … 주소가 생기면 저절로 다시 요청합니다" 로 바뀌었습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션. 거울을 거는 세션이 0.2.14 이어야 합니다. 작업 세션은 0.2.13 이상이면 됩니다.
