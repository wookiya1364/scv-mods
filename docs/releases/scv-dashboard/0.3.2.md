# scv-dashboard 0.3.2

입력창 위의 기어 줄을 고쳤습니다.

## 바뀐 것

- **버튼이 둘입니다: [사용함] [사용안함].** [사용함]을 누르면 입력창의 글이 그 기어를 쓰라는 한 줄과 함께 바로 보내지고 입력창이 비워집니다. [사용안함]을 누르면 이번 글에는 그 기어를 쓰지 않습니다. 0.3.1 에는 [안 씀] 하나뿐이었습니다.
- **설명이 잘리지 않습니다.** 기어가 하는 일을 끝까지 보여 줍니다. 0.3.1 은 60자에서 잘랐습니다.

## 알아 둘 것

- 버튼을 누르지 않고 그대로 보내도 0.3.1 처럼 그 기어를 쓰라는 한 줄이 붙습니다. 쓰지 않으려면 [사용안함]을 누르고 보내세요.
- 낱말이 겹쳐 뜻과 다르게 뜰 수 있습니다(예: 릴리스를 묻는 질문에 릴리스 검사 기어). 그럴 때는 [사용안함].
