# scv-dashboard 0.8.0

SCV 창이 움직임으로 상태를 알리고, 내 차례를 맨 위의 카드로 알리고, 동시에 하는 두 일을 나란히 보입니다.

## 바뀐 것

- **단계 흐름이 움직입니다.** 일하는 중인 단계의 점이 번지고, 단계가 끝난 순간 초록 빛이 다음 단계로 한 번 내려갑니다. 내 차례에는 아무것도 움직이지 않습니다 — 멈춘 창이 "지금은 내 차례"라는 뜻입니다. '움직임 끄기' 단추로 끄면 예전의 멈춘 그림으로 보이고, 고른 값은 남습니다. 기기에서 움직임 줄이기를 켜 두었으면 움직이지 않습니다.
- **선이 끝까지 이어지고 꼭짓점이 제목 줄에 맞습니다.** 움직임을 켠 화면에서 단계와 단계 사이의 선이 끊기지 않고(끝난 단계 뒤는 초록, 그 밖은 회색 실선), 꼭짓점이 단계 제목과 같은 높이에 있습니다.
- **열린 질문이 맨 위의 카드로 뜹니다.** Claude 가 선택 창으로 물으면 창 맨 위에 보라색 카드가 뜨고, 보기 단추를 누르거나 직접 써서 답할 수 있습니다. 대화창의 선택 창은 그대로이고, 어느 쪽에서 답해도 됩니다. 요구를 확인받는 질문에는 Claude 가 이해한 것 세 줄(목표 · 안 하는 것 · 확인 방법)이, 결과를 확인받는 질문에는 증거(그림 · 영상 · 페이지)가 카드에 함께 보입니다. 카드로 답한 것도 SCV 의 선택 기록에 남습니다.
- **두 일을 동시에 할 때 두 칸으로 보입니다.** SCV 가 하던 일과 새 일을 갈라 동시에 진행하면(SCV 본체 0.106.0 부터), 가른 단계 밑에 두 일이 '분기' · '원본' 이름표를 달고 나란히 놓이고 각자의 단계와 상태가 보입니다. 맨 위에는 '지금 · 돌아갈 곳' 칸이 뜹니다. 합친 뒤에는 그 자리에 합친 때 · 같은 줄 충돌 여부 · 달라진 결과 · 다시 맞추는 일이 보입니다.
- **두 칸 안의 단계도 누를 수 있습니다.** 누르면 흐름 아래에 그 단계의 자세한 칸(하는 일 · 지금 진행 · 이 단계에서 한 일)이 뜹니다. 상대 일의 단계면 이름표와 일 이름이 함께 보입니다.
- **차례가 바뀌었습니다.** 내 차례 카드가 맨 위에 오고, '지금 하는 일' 한 줄은 단계 흐름 아래로 갔습니다.

## 알아 둘 것

- 움직임 하나에 뜻 하나만 둡니다: 번지는 점 = 일하는 중, 내려가는 빛 = 단계가 끝남(한 번), 멈춤 = 내 차례.
- 카드의 단추가 보내는 답은 보기 글과 글자까지 같습니다. 거울 화면(다른 컴퓨터)에서는 카드의 내용만 보이고 단추는 없습니다.
- 두 칸은 계획이 갈라져 있을 때만 보입니다. 가르기와 합치기는 SCV 본체(0.106.0)와 그 판을 실은 포장이 합니다 — 그 전 판에서는 두 칸이 뜰 일이 없고 나머지는 그대로 됩니다.
- 움직임을 끈 화면의 단계 그림과 제목 자리는 예전 그대로입니다(끝나지 않은 단계 뒤의 점선 포함). 가른 일이 있을 때만 끈 화면에도 두 칸 옆의 선이 더해집니다.
- 두 칸의 단계 이름이 칸보다 길면 줄여 보입니다. 누르면 자세한 칸에 전체가 보입니다.
- 확인은 모드 시험 328개로 했습니다(새 시험 34개). 실제 앱에서 본 것: 움직임, 카드로 답하기, 두 칸과 합친 뒤의 모습, 칸 안의 단계 누르기. 아직 보지 못한 것: 실제 앱에서 카드로 답한 것이 선택 기록에 남는지, 원격 화면의 모습. 움직이는 견본에 있던, 답한 뒤 잠깐 뜨는 '확인됨' 표시는 넣지 않았습니다.
