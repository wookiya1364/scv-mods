# scv-dashboard 0.2.9

0.2.8 의 '거울 세션 열기' 링크는 채팅 안에서 눌러도 아무 일이 없었습니다. 이제 터미널에 붙여 넣는 한 줄로 같은 일을 합니다.

## 바뀐 것

- Claude 앱은 채팅 속 앱 전용 링크(`claude://…`)를 눌러도 열지 않습니다. 리눅스 앱에서 확인했습니다. 같은 링크를 그 기기 터미널에서 열면 새 세션이 열리고 입력창에 `/scv-mirror <주소>`가 채워집니다.
- 그래서 `/scv-dashboard` 응답이 링크 대신 그 기기 터미널에 붙여 넣을 한 줄을 보여 줍니다. 리눅스는 `xdg-open '<링크>'`, 맥은 `open '<링크>'`. 열린 새 세션에서 Enter만 누르면 됩니다.
- 기존 `/scv-mirror <주소>` 줄도 그대로 있습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
