# scv-dashboard 0.2.15

단계를 누르면 그 단계가 만드는 순수함수와, 그 단계 동안 새로 만든 함수 · 가져다 쓴 함수가 보입니다. "Bash: …" 같은 도구 호출 줄만 보여서는 무엇을 하려는지 알기 어려웠습니다.

## 바뀐 것

- **하는 일**: 단계 줄 끝에 적힌 함수마다 `1. scv_step_line (조립) 매 턴 안내 한 줄을 만든다` 처럼 이름 · 종류 · 역할을 보여 줍니다. 역할은 프로젝트의 순수함수 사전(`scv/core/catalog/pure/`)에서 먼저 찾습니다. 사전에 없으면 이번에 만든 함수의 주석을, 그것도 없으면 계획서 함수 표의 '하는 일'을 씁니다. 함수가 없는 단계는 `순수함수 없음 — <줄 끝 글>` 로 보입니다.
- **이 단계에서 한 일**: `새로 만듦 2 · 사전 등록: 고르기 1 · 조립 1 · 가져다 씀 0` 처럼 한 줄로 셉니다. 그 아래에는 함수마다 한 줄씩 나옵니다. 그 단계 동안 쓰거나 고친 코드에서 `@pure` · `@deterministic` 표식 밑에 정의된 함수는 '새로 만듦'입니다. 사전이나 이 계획의 다른 단계가 만든 함수를 부르면 '가져다 씀'이고, 앞 단계가 만든 함수에는 '(2단계에서 만든 것)'이 붙습니다. 표식을 읽는 규칙은 SCV 코어의 사전 만들기와 같습니다.
- 도구 호출 줄은 `▸ 도구 호출 n건` 한 줄로 접히고, 누르면 펼쳐집니다.
- 단계마다 한 일은 프로젝트별로 저장되어, 새 세션에서도 보입니다. 이 버전을 설치하기 전에 끝난 단계는 기록이 없어 0 으로 보입니다.
