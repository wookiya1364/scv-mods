# scv-dashboard 0.6.2

자동 비우기 기준이 프로젝트에 저장되고, 칸의 글이 세 줄로 짧아졌습니다.

## 바뀐 것

- **기준(%)과 끄기/켜기가 프로젝트의 설정 파일에 남습니다.** 전에는 이 컴퓨터 전체에 한 칸으로만 기억해서, 대화가 비워진 뒤 기준이 50% 로 돌아와 다시 바꿔야 했습니다. 이제 `scv/scv_settings.json` 의 두 키에 저장합니다 — `SCV_CLEAR_PERCENT`(10 ~ 95) 와 `SCV_CLEAR_AUTO`(`on` | `off`). 창은 프로젝트를 새로 읽을 때마다 그 파일에서 읽으므로, 비운 뒤에도 새 세션에서도 정해 둔 값이 보입니다. 값이 없으면 켜짐 · 50% 입니다.
- **칸의 글이 세 줄입니다.** `자동 비우기 50% 넘으면 [끄기]`, 막대(◀ ▶), `마지막 비우기 50% → 3% · 1초 걸림`. 긴 설명 줄과 막대 옆에 한 번 더 적던 `비우기 기준 50%` 는 없앴습니다. 껐을 때는 `자동 비우기 꺼짐 [켜기]` 입니다.
- **거울에서 눌러도 같습니다.** 거울 화면에서 누르면 작업 세션이 자기 프로젝트의 설정 파일에 씁니다.

## 알아 둘 것

- 설정 파일은 git 에 올라가는 파일입니다. 기준을 바꾸면 그 프로젝트에 바뀐 파일로 잡힙니다.
- 설정 파일이 있는 프로젝트는 컴퓨터에 기억해 둔 옛 값을 더는 읽지 않습니다. 0.6.1 에서 바꿔 둔 기준은 한 번 다시 정해야 합니다(그 전에는 50%).
- 설정 파일이 없는 폴더(SCV 프로젝트가 아닌 곳)는 전처럼 컴퓨터에 기억합니다.
- 설정 파일에 쓰지 못하면 칸에 `설정 파일에 저장하지 못함 — 다시 눌러 주세요` 가 보이고, 값은 파일에 있는 것으로 돌아갑니다.
- 확인은 모드 시험 265개와, 실제 설정 쓰기 명령을 임시 프로젝트에 돌려 본 것으로 했습니다(한 번에 55 ~ 69 ms). 실제 앱에서 비운 뒤에도 값이 남는 것은 아직 보지 못했습니다. 전에 50% 로 돌아오던 직접 원인은 확인하지 못했습니다 — 파일은 매번 다시 읽으므로 원인과 무관하게 남습니다.
