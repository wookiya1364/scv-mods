# scv-dashboard 0.2.19

닫은 SCV 칸이 메시지를 보낼 때마다 다시 열리지 않습니다. 다시 보려면 `/scv-panel` 을 입력합니다.

## 바뀐 것

- 0.2.18 까지는 칸을 닫아도, 다음 메시지를 보내면 칸이 저절로 다시 열렸습니다. 이제는 닫으면 닫힌 채로 있습니다.
- 칸을 여는 명령 `/scv-panel` 을 새로 만들었습니다. 예전 `/scv-dashboard` 도 같은 일을 하므로 그대로 쓸 수 있습니다. (모드 명령 이름에는 쌍점을 쓸 수 없어 `/scv:panel` 대신 붙임표로 만들었습니다.)
- 세션을 시작할 때와 다른 기기의 앱이 이 세션에 붙을 때는 지금처럼 칸이 한 번 열립니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
