# scv-dashboard 0.2.30

코드에 주석을 두지 않는 프로젝트(SCV 0.98.0+ — 순수 함수 사전이 원본)에서도 단계가 만든 함수를 보여 줍니다.

## 바뀐 것

- 단계가 쓴 코드에 함수 표식 주석이 없으면, 그 코드가 정의한 이름 중 사전(`scv/core/catalog/pure`)에 있는 것을 '만든 함수'로 봅니다(역할 · 종류는 사전에서).
- 사전을 읽을 때 `effects.md`(부수효과 함수) · `notes.md`(메모)는 순수 함수 종류로 세지 않습니다.

## 알아 둘 것

- 주석 표식이 있는 프로젝트는 이전과 같습니다.
