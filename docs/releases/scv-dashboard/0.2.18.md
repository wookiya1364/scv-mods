# scv-dashboard 0.2.18

단계 상세가 줄글 대신 함수마다 불릿 하나, 그 아래 들여 쓴 설명 한 줄로 보입니다.

## 바뀐 것

- **하는 일**: 함수마다 `• 이름 (종류)` 줄을 쓰고, 그 아래에 설명 한 줄을 들여 씁니다. 설명은 사전 역할에서 첫 ` — ` 앞까지만 씁니다. 함수가 없는 단계는 `순수함수 없음` 아래에 줄 끝 글을 들여 씁니다.
- **이 단계에서 한 일**: `새로 만듦 N` · `가져다 씀 N` 소제목 아래에 함수마다 불릿 한 줄을 씁니다. 하는 일에 이미 나온 함수는 이름만 쓰고, 나오지 않은 함수는 아래에 설명 한 줄을 더 씁니다. 0.2.15 의 `사전 등록: …` 줄은 없앴습니다(종류는 하는 일에 이미 보임).
- 도구 호출은 지금처럼 `▸ 도구 호출 n건` 으로 접혀 있습니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
