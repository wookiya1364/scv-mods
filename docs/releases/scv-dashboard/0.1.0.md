# scv-dashboard 0.1.0

첫 릴리스입니다. Claude 데스크톱 앱의 로컬 세션 오른쪽에 SCV 칸을 띄워, 계획이 어디까지 왔는지 기다리지 않고 볼 수 있게 합니다. 칸은 프로젝트 파일을 읽기만 하고 바꾸지 않습니다.

## 들어 있는 것

- 맨 위 한 줄 요약: 어디까지 왔는지 · 막힌 것 · 남은 시간. 그 아래 다음 할 일과, 그 명령을 입력창에 넣는 버튼 · 복사 버튼. 차례가 끝나면 같은 명령이 입력창의 흐린 제안(Tab)으로도 뜹니다.
- 계획 진행률(끝난 단계 / 전체)과 신호등 막대, 단계 흐름(끝 · 진행 · 막힘 · 대기, '지금 여기' 표시). Claude 가 일하면서 보내는 단계 신호로 진행률이 실제로 움직입니다.
- 지금 하는 일: 단계 · 도구와 대상 · 걸린 시간 · 할 일 목록 · 일하는 에이전트마다 한 줄(5개까지, 나머지는 개수).
- 자리 비운 사이: 마지막 메시지 뒤에 끝난 단계 · 시험 결과 · 기다리는 것.
- 남은 시간 추정 — 단계에 걸린 시간으로 계산하고, 늘 추정이라고 표시합니다.
- 막힘 카드: 답 기다림 · 허락 기다림 · 오류나 거절로 멈춤 · 시험 실패.
- 시험 결과(TESTS.md 시나리오별). 지난 결과가 모드 저장소에 남아 새 세션에서도 보입니다.
- 사용 한도: 5시간 · 7일 사용률과 5시간 초기화 시각.
- 알림: 답이나 허락을 기다릴 때, 시험이 실패할 때, 2분 넘은 일이 끝날 때, 오류나 거절로 멈출 때, 사용 한도가 90%를 넘을 때(기간마다 한 번). 앱 알림이 없으면 시스템 알림으로 대신하고, 원격 연결 중이면 휴대폰으로도 갑니다.
- 세션 폴더에서 위로 올라가며 가장 가까운 `scv/` 를 찾아, 하위 폴더에서 연 세션도 계획을 봅니다.
- 최근 `/scv:dreams` 요약과 개선 항목, 보고서 열기 버튼.

## 아직 앱에서 확인하지 않은 것

입력창 넣기 · Tab 제안 · 사용 한도 정보 · 휴대폰 알림 · 허락 기다림 신호가 데스크톱 앱에서 실제로 오는지는 아직 보지 못했습니다. 오지 않으면 그 자리는 복사 버튼과 시스템 알림으로 남습니다.

## 이름: scv-hello → scv-dashboard

첫 릴리스 전에 이름을 scv-hello 에서 scv-dashboard 로 바꿨습니다. 칸을 여는 명령은 `/scv-dashboard`, Claude 가 단계를 알리는 도구는 `mcp__scv-dashboard__scv_step` 입니다. 마켓 목록에는 scv-hello 가 더 없고, 옛 이름 → 새 이름 표(renames)만 남아 옛 설치가 '못 찾음' 오류를 내지 않게 합니다. 이름별로 따로 두던 기억(지난 시험 결과 · 단계 신호)은 새 이름에서 처음부터 다시 쌓입니다.

## 받는 법

처음 설치하거나 scv-hello 를 쓰던 컴퓨터: 옛 scv-hello 를 지우고(`/scv:mods-remove`, 또는 셸에서 `claude plugin uninstall scv-hello@scv-mods`) 새 scv-dashboard 를 설치합니다(`/scv:mods-install`, 또는 `claude plugin install scv-dashboard@scv-mods`).

그다음부터는 `/scv:mods` (SCV 0.70.0 이상). 또는 셸에서 `claude plugin marketplace update scv-mods` 다음 `claude plugin update scv-dashboard@scv-mods`. 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
