# scv-dashboard 0.2.17

진행 중인 계획이 없을 때, 칸은 가장 최근에 보관한 계획을 보여 줍니다.

## 바뀐 것

- 0.2.16 까지는 '최근 끝난 계획'을 계획을 만든 날짜(폴더 이름)순으로 골랐습니다. 그래서 오늘 보관한 계획이 10월 22일에 만든 것이면, 10월 25일에 만든 다른 계획이 대신 보였습니다.
- 이제 각 계획의 보관 기록(`ARCHIVED_AT.md`)에 적힌 날짜가 늦은 계획을 앞에 둡니다. 같은 날 보관한 계획끼리는 이름순이고, 보관 기록이 없는 계획은 맨 뒤로 갑니다. 보관 기록에는 날짜만 있어서 같은 날의 순서는 가려내지 못합니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
