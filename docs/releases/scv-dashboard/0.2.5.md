# scv-dashboard 0.2.5

단계 흐름에서 함수를 만들지 않는 단계도 '하는 일'이 보입니다.

## 바뀐 것

- 0.2.4 까지는 계획서 파이프라인 표와 이어진 단계만 '하는 일'이 나왔습니다. 시나리오 · 시험 · 녹음처럼 함수를 만들지 않는 단계는 "계획서 파이프라인 표에서 이 단계가 하는 일을 찾지 못했습니다"로 비었습니다.
- 이제 단계 줄 끝에 ` — <하는 일 한 줄>`(백틱 없이)을 적으면 그 한 줄이 '하는 일'로 보이고, 단계 이름에는 대시 앞까지만 남습니다. SCV 0.70.3 계획서 양식이 그렇게 적게 합니다.
- `` — `단계` `` 처럼 백틱으로 표와 잇는 줄은 그대로입니다.
- 주의: 대시 뒤가 백틱이 아닌 옛 단계 줄은 이제 대시 앞까지만 이름이 되고, 뒤쪽은 '하는 일'로 보입니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
