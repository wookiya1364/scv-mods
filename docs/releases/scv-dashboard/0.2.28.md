# scv-dashboard 0.2.28

여러 단계를 함께 하면, 함께 하는 단계가 모두 '진행 중'으로 보입니다.

## 바뀐 것

- 단계 알림(scv_step)의 '시작'과 '막힘'을 끝나지 않은 단계면 어느 자리든 받습니다. 전에는 끝나지 않은 첫 단계에만 받아서, 둘째 단계의 시작을 알리면 "진행은 지금 단계에만 보낼 수 있습니다"로 거절했고 화면에는 한 단계만 진행 중으로 보였습니다.
- 시작했다고 알린 단계는 모두 진행 중으로 그립니다 — 단계 줄마다 '진행 중 ◀ 지금 여기', 세는 줄 '진행 3', 맨 위 줄 '2~4단계 진행 중'(이어진 번호 셋 이상은 줄여 씀).
- 알림의 답이 지금 진행 중인 단계를 모두 말합니다(`진행 1/6 · 진행 중: 2~4단계`). 번호를 잘못 보냈으면 답에서 바로 보입니다.
- 한 단계가 끝나도, 아직 하는 중인 다른 단계에 작업 기록이 계속 적힙니다(가장 늦게 시작해 아직 끝나지 않은 단계).
- 이미 끝난 단계에 시작이나 막힘을 보내면 거절합니다.

## 알아 둘 것

- 단계를 차례로 하는 계획의 화면은 전과 같습니다.
- 진행 중이라고 알린 단계가 있는 동안에는, 아무도 시작을 알리지 않은 단계를 진행 중으로 짐작하지 않습니다. 알린 진행이 없으면 전처럼 끝나지 않은 첫 단계가 진행 중입니다.
- 계획 문서의 단계 줄에 손으로 남긴 표시(`[~]` · `[!]`)는 전처럼 첫 단계에서만 읽습니다. 뒤 단계를 여는 것은 단계 알림과 계획의 진행 줄뿐입니다.
- 시작만 알리고 끝을 알리지 않은 단계는 계속 진행 중으로 남습니다.
- 남은 시간 추정은 단계를 차례로 한다고 보고 셉니다 — 함께 하는 단계가 많으면 실제보다 길게 나옵니다.
- 사용자 차례 · 답 기다림 · 시험 실패는 진행 중인 단계 모두에 표시됩니다.
