# scv-dashboard 0.2.21

대시보드가 계획 파일과 늘 같게 보입니다. 단계 보고가 빠져도, 계획 파일에 남은 진행 줄로 단계 상태를 채웁니다. SCV 0.87.0 이상과 함께 씁니다.

## 바뀐 것

- 계획 파일의 진행 줄("N단계 시작 · 끝 · 막힘")로 단계 상태를 채웁니다. 단계 보고 도구를 부르지 않은 단계도 계획 파일대로 보입니다.
- 계획의 변경 이력을 최근 것부터 3개 보여 줍니다 — 단계 추가 · 보류 · 진행 · 선택 창 답.
- `2b.` 처럼 글자가 붙은 단계 번호도 단계로 셉니다.

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
