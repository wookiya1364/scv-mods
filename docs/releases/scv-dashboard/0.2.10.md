# scv-dashboard 0.2.10

`/scv-dashboard` 응답이 다시 짧아집니다.

## 바뀐 것

- 0.2.8 · 0.2.9 에서 넣은 '거울 세션 열기' 링크와 터미널에 붙여 넣는 한 줄(`xdg-open` · `open`)을 뺐습니다. 채팅 속 링크는 앱이 열지 않고, 터미널 한 줄도 결국 복사해 붙여 넣어야 해서 `/scv-mirror` 줄을 쓰는 것보다 나을 게 없었습니다.
- 응답은 0.2.7 때처럼 이것 하나만 안내합니다: 그 기기에서 연 다른 세션에서 `/scv-mirror <주소>`.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
