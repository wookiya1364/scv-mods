# scv-dashboard 0.2.27

거울을 켜 두어도 작업 세션의 대화에 '…세션에서 메시지 받음' 줄이 쌓이지 않습니다.

## 바뀐 것

- 보는 세션(거울)이 소식이 없어도 스스로 다시 요청하지 않습니다. 전에는 10분 동안 아무것도 못 받으면 다시 요청했고, 작업 세션이 쉬는 동안에는 그때마다 작업 세션의 대화에 줄이 하나씩 생겼습니다. 이제 줄은 거울을 켤 때 한 번만 생깁니다.
- 거울 줄 옆에 '다시 요청' 버튼이 생깁니다. 누르면 한 번 다시 요청하고, 보냈는지 못 보냈는지 알려 줍니다.
- 10분 넘게 받지 못했으면 거울 줄이 '10분 넘게 소식 없음(쉬는 중이거나 끊김)'이라고 말합니다.

## 알아 둘 것

- 그 줄 자체는 Claude 앱이 그립니다. 다른 세션에서 글이 오면 대시보드가 가로채도 한 줄이 생기므로, 대시보드는 보내는 글을 줄이는 것까지만 할 수 있습니다.
- 작업 세션을 새로 열면 거울이 조용히 멈출 수 있습니다. 그때는 '다시 요청'을 누르세요.
- 두 세션 모두 0.2.27 이어야 합니다 — 다시 요청하는 쪽은 보는 세션입니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
