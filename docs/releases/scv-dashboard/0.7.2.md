# scv-dashboard 0.7.2

문서만 바뀐 판입니다. 창의 동작은 0.7.1 과 같습니다.

## 바뀐 것

- **README 가 지금 판을 따라갑니다.** 기능 목록이 0.2 판대에서 멈춰 있었습니다. 맨 위 칸(폴더 · 브랜치 · 컨텍스트 · 사용 한도 · 묻기 방식 · 자동 비우기 · 언어 · 기어 · 낱말 사전), 창에서 기어 바로 돌리기, 자동 비우기와 그 뒤에 다시 보이는 직전 대화 · 할 일 목록, 거울에서 누르기를 적었습니다.
- **실제 화면 이미지가 들어갔습니다.** 실제 세션의 SCV 창을 찍은 이미지입니다. 폴더 경로는 저장소 이름만 남겼습니다.
- **설치 · 업데이트 안내에 SCV 명령을 더했습니다.** SCV 가 있으면 `/scv:mods-install` 로 설치하고, `/scv:update` 가 SCV 와 모드를 함께 올립니다.

## 알아 둘 것

- 모드의 코드는 0.7.1 과 같습니다. 업데이트해도 달라지는 것은 판 번호뿐입니다.
