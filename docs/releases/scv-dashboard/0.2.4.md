# scv-dashboard 0.2.4

두 세션이 서로를 거울로 걸어 둘 다 멈추는 일을 막았습니다.

## 바뀐 것

- 0.2.3 까지는 맥미니 세션이 맥프로 작업 세션을 거울로 보는 중에, 작업 세션에서 다시 맥미니 세션으로 `/scv-mirror` 를 걸 수 있었습니다. 그러면 두 세션이 서로를 베끼기만 하고 아무도 자기 계획 파일을 읽지 않아, 두 칸이 모두 멈췄습니다.
- 이제 지금 이 세션을 거울로 보고 있는 세션으로는 거울이 걸리지 않습니다. "그 세션은 지금 이 세션을 거울로 보고 있습니다 — … 거울은 작업 세션이 아닌 다른 세션에서 겁니다" 라고 알려 주고, 아무것도 보내지 않습니다.
- 이미 서로 걸려 있다면 한쪽에서 `/scv-mirror stop` 으로 풉니다.

## 받는 법

양쪽 컴퓨터 모두에서 `/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
