# scv-dashboard 0.3.3

대화가 길어지면 자동으로 가볍게 합니다.

## 바뀐 것

- **턴이 끝날 때 컨텍스트가 50% 이상이면 대화를 가볍게 합니다.** 대화가 길어질수록 Claude 가 답할 때마다 다시 읽는 양이 늘어 느려지고 토큰을 많이 씁니다(실제로 한 세션은 호출마다 약 83만 토큰을 다시 읽고 있었습니다). 이제 그 지경이 되기 전에 줄입니다.
- **먼저 빠른 길을 씁니다 — 모델 없이.** SCV 가 매 턴 적어 둔 대화 기록(`scv/conversations`)의 끝부분, 진행 중인 계획의 상태, 최근 세 턴의 글로 앞부분을 바꿔 끼웁니다. 요약하는 모델 호출이 없어 바로 끝납니다. 실제 세션 한 번으로 확인한 값: 45,301 → 367 토큰, 0.014초, 그 뒤 질문에 기록에만 있던 내용을 맞게 답함.
- **기록이 없으면 자동 요약으로 넘어갑니다.** 이때는 Claude 의 정리 기능이 한 번 돕니다.
- **창에 한 줄.** 컨텍스트 칸에 "대화가 길어지면(50%) 자동으로 가볍게 함 [끄기]"와, 가볍게 한 뒤의 결과 한 줄(예: 기록으로 바꿔 끼워 가볍게 함 62% → 8% · 1초)이 보입니다. 끄면 다음 세션에도 꺼진 채로 남습니다.

## 알아 둘 것

- 일하는 도중에는 줄이지 않고, 턴이 끝났을 때만 합니다. 한 번 한 뒤 5분 안에는 다시 하지 않습니다.
- 바꿔 끼운 뒤 Claude 는 그 전의 도구 출력을 보지 못합니다. 필요한 것은 기록 파일을 다시 읽습니다 — 바꿔 끼운 글의 맨 위에 기록 파일의 자리가 적혀 있습니다.
- 직접 친 `/compact` 와 Claude 자체의 자동 정리는 건드리지 않습니다.
- 가볍게 할 때 대화에 정리 명령이 한 번 돈 것으로 보입니다(모드가 그 명령을 대신 돌리고, 답을 기록으로 채웁니다).
- 확인은 화면 없는 실행 한 번과 시험 6개로 했습니다. 앱 화면에서의 모습은 아직 보지 못했습니다 — 이상하면 [끄기].
- 기본은 켬입니다. 원하지 않으면 창의 [끄기]를 누르세요.
