# scv-dashboard 0.2.22

변경 이력이 있는 계획을 열면 SCV 칸이 비어 있던 문제를 고쳤습니다.

## 바뀐 것

- 0.2.21 에서는 계획에 변경 이력이 있으면 칸이 그려지지 않았습니다. 칸에는 "Nothing to show yet" 만 보였습니다. 변경 이력 줄을 그리는 코드가 화면 그리는 함수와 같은 이름을 썼기 때문입니다.
- 이제 변경 이력이 있는 계획도 칸이 그려지고, 최근 이력 3개가 보입니다.

## 받는 법

`/scv:mods` (SCV 0.70.0 이상). 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
