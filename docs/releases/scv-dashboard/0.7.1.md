# scv-dashboard 0.7.1

대화를 비운 뒤 할 일 목록을 항상 다시 띄우고, 끝난 일은 끝난 것으로 띄웁니다.

## 바뀐 것

- **목록이 있으면 항상 다시 띄웁니다.** 0.7.0 은 끝나지 않은 할 일이 있을 때만 띄웠습니다. 이제 모두 끝난 목록도 띄워, 끝난 일 · 하는 중인 일 · 남은 일이 함께 보입니다.
- **마무리된 일은 끝난 것으로 띄웁니다.** 0.7.0 은 Claude 의 마무리 호출(`mcp__ccd_turn__wrap_up`)을 듣지 않아, 이미 끝난 일의 목록이 "하는 중"으로 다시 떴습니다(실제 세션에서 봤습니다). 이제 마무리 호출로 끝난 턴의 목록은 모두 끝난 것으로 띄웁니다 — 앱이 그때 목록을 닫는 것과 같습니다. 뒤에서 도는 일이 남아 있으면 Claude 가 보낸 상태 그대로 띄웁니다.

## 알아 둘 것

- 다시 띄운 목록은 그 턴의 답이 끝나면 앱이 내립니다. 앱은 Claude 가 일하는 턴 동안에만 목록을 그립니다 — 턴을 끝내는 네 가지 방법을 실제 앱에서 해 봤고 네 번 모두 목록이 사라졌습니다. 창이 바꿀 수 없는 부분입니다.
- 걸리는 시간은 0.7.0 의 예상(약 5초)보다 깁니다. 처음 실제로 비운 때에 목록은 비운 뒤 10.7초에 떴습니다(턴 시작 검사 1.35초, Claude 가 첫 출력을 내기까지 8.6초 — 한 번의 측정).
- 비울 때마다(목록이 있으면) 짧은 턴이 하나 더 듭니다. 처음 실제로 비운 때에 그 턴은 13.7초였습니다.
- 목록이 없을 때, 비우기가 확인되지 않았을 때, 사람이 직접 비웠을 때, 거울 세션에서는 0.7.0 과 같이 글을 보내지 않습니다.
- 확인은 모드 시험 294개로 했습니다(새 시험 3개). 실제로 비운 뒤 끝난 목록이 끝난 것으로 뜨는 모습은 아직 보지 못했습니다.
