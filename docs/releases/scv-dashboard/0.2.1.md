# scv-dashboard 0.2.1

거울 칸이 권한 모드 '자동'인 세션에서도 열리게 고쳤습니다.

## 고친 것

- 0.2.0 에서는 권한 모드가 '자동'인 세션에서 `/scv-mirror` 가 "거울 요청을 보내지 못했습니다: … auto mode classifier gave no verdict for SendMessage" 로 멈췄습니다. 확장 기능이 보내는 거울 메시지도 자동 판정을 거쳤는데, 사람이 시킨 일이 아니어서 판정이 나오지 않았기 때문입니다.
- 이제 SCV 가 스스로 보내는 메시지(거울 요청 · 상태)는 허락을 묻지 않습니다. 휴대폰 알림과 같은 방식입니다. Claude 가 직접 보내는 메시지는 전과 같이 심사합니다.

## 받는 법

양쪽 컴퓨터 모두에서 `/scv:mods` (SCV 0.70.0 이상). 또는 셸에서 `claude plugin marketplace update scv-mods` 다음 `claude plugin update scv-dashboard@scv-mods`. 그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션.
